# 测量与检查工具

日常运行只需打开两版主程序或扰动窗口，不需要直接运行这里的测量模块。

| 文件或目录 | 功能 | 何时运行 |
| --- | --- | --- |
| `measurements.py` | 同步采样惯性/重力/接触力，记录关节限位与可选加速度对账 | 控制循环自动调用 |
| `flat_observation.py` | 平放版每拍预测、每个物理步状态及失败现场 | 主程序自动调用 |
| `handheld_observation.py` | 手持版对应观测，额外保存完整接触力矩等记录 | 主程序自动调用 |
| `tests/`、`run_checks.py` | 参数兼容、参考导数、采样、限位和启动回归检查 | 修改代码后手动运行 |
| `calibration/` | 两种接触布局的离线刚度标定工具 | 场景改变、确需重新标定时手动运行 |
| `legacy_reconciliation.py` | 旧场景的启动几何对账代码和历史常数 | 历史兼容，不作为当前实验验收入口 |

原工程运行回归：`python diagnostics/run_checks.py`。回归套件同时使用两个控制器，完整套件只放在原工程；拆分分享版只带各自运行必需的诊断模块及对应标定脚本。

标定工具可从工程目录调用，例如 `python diagnostics/calibration/calib_exp2_contact.py`。它们不会自动修改主程序的刚度参数，但会构建或刷新运行场景，运行时应与主实验错开。

`--dynamics_diag` 仍默认关闭；正常接触测量、限位记录和绘图数据继续保留。整理只改变文件位置，不能把诊断记录误当成额外控制反馈。

根目录的 `exp2_diagnostics.py` 和 `exp2_experiments/*_observation.py` 是短兼容入口，供旧脚本使用；修改实现请直接编辑本目录。历史对账工具保留旧逻辑与旧常数，其中包含会改写运行模型的旧加载流程，不应直接用于验证当前场景。
