# 测量锚定理想弹簧：实现与固定参数对照

2026-10-12。本轮由 Astra 实现关键模型并独立对账，Luna 顺序运行固定实验并整理日志，主代理审查实现、限位和结论。

新公式已经接入平放和手持的共享控制器，软件及逐节点公式核验通过；闭环结果存在取舍，未达到全面替换默认模型的要求。默认仍是 `smooth_positive`，新模型通过 `--normal_force_law measured_anchored_ideal` 显式启用。本轮没有调参。

## 实际修改

- 每次控制更新保存当前夹持面中心的世界 x 间距和左右测量法向力。预测总力为 `max(0, measured_normal + kx * (anchor_gap - predicted_gap))`，再按左负右正赋予世界 x 符号；全部 N+1 节点共用本拍锚点。
- 总预测力同时用于力残差、力导数、接触面 Jacobian 的关节载荷映射和模型平衡初值。力导数直接对总预测力求导，不能继续对旧名义力求导。
- 完整实测接触关节载荷减去当前模型法向载荷作为冻结余项；当拍法向力不会重复计入。非 x 测量口径维持原值。
- 旧两律的完整参数仍为225维，新律在末尾追加间距和两侧正法向力，共228维。原有槽位不改。日志同时保存完整参数及布局；旧兼容数组本身不足以重放新模型。
- 冷/热启动仍写满11个状态节点，两次预热、物理关节边界、28状态/14力矩、协同残差、代价和求解器设置均保留。缓存升级为 `shared_v3`，接触律和布局隔离；新指纹首次编译后复用。
- 两版每2ms保存实际接触数、法向力、状态和限位反力；每次控制更新保存11节点状态、总预测力、力导数、混合残差、参数和节点时间。日志不参与控制反馈。

涉及 `nmpcc/{config,model,parameters,controller,data,ocp}.py`、场景CLI/配置、`experiments/recording.py`、两版输出模块及回归测试。详见同级《测量锚定接触模型.md》。

## 预测链路独立核验

全部24组、232,716个预测及启动节点公式核验通过，另有4,230个严格同拍测量日志交集通过。采用独立NumPy表达式核对力、力导数、混合误差及导数；独立MuJoCo几何核对夹持面中心，并检查当前法向关节载荷加冻结余项是否重建完整接触载荷。最大总力差0，力导数差4.55e-13 N/s，法向载荷对账差3.78e-13 N·m，几何间距差5.55e-16m，有限差分力导数最大差4.49e-7 N/s。

同一保存状态、力矩、惯性、重力、负载、参考下，重新锚定三种公式后，当前力、关节加速度和混合误差相同，改变的是预测梯度。手持保持1.5s例子：gap=0.240041004678m，略大于rest_gap=.24m；原平滑有效刚度1184.85 N/m，旧理想为0，新测量锚定为2419.3 N/m。这验证了新模型确实修正旧名义零力区的预测斜率。

新平放三组100%预测节点同时处于两种理想模型的正分支，因而旧理想和测量锚定轨迹数值相同，是局部代数等价。新手持预测全部处于正总力分支，但旧几何名义正分支仅覆盖约37%–80%，所以两种理想模型出现不同闭环行为。这些中心间距数值不是实际穿透深度。

启动文件没有保存所有混合残差/载荷字段，启动部分对这些量是离线重算，而非与不存在的日志字段比较。测量相等核验也只针对严格同拍交集，不将稀疏日志插值成额外证据。

## 触限核查

未发现初态、初始化、关节索引或边界配置错误：三律的初始q/dq、平衡种子、首拍状态与所采样M/G/负载/参考相同；保存的joint ID/range与MJB一致，物理关节角及上下界余量重算一致。

新手持0.8/0.2触限关节为 `openarmx_right_joint6`（控制器排序的左臂第6关节），上限0.75rad，在4.568–4.616s共25步触限，最大越界7.87574e-5rad。0/0同一关节在1.026–1.038s及1.158–1.178s共18步触限，最大越界3.76186e-4rad。

0.8/0.2触限前4.566s测得该关节0.749980763rad，余量仅1.92366e-5rad；该拍整个预测时域均未超界，实际2ms后却跨界。证据支持真实闭环约束跟踪差异，可能涉及10ms预测节点之间运动及模型偏差，尚不能断言单一原因。没有放宽限位、裁剪测量轨迹或调参掩盖此结果。

## 结论和边界

本轮证明新公式及其导数/载荷/参数链路正确，实现了当前测量预载下的完整局部弹簧斜率；未证明全部搬运指标改善，也没有解决持续滑移、短行程跟踪或预测节点间触限。

论文的协同误差、耦合系数和OCP结构不变；法向接触预测属于实现中的物理近似，本轮改变了这一子模型，不能说成完全复现论文。仍冻结惯性、重力、接触余项，仍不预测箱体接触几何和摩擦；总力归零时冻结余项不会自动消失。新增零力截断虽经单元检查覆盖，本轮新模型闭环未实际进入该分支，不能据此宣称接触断开时可靠。

因此保留原平滑默认值，将新模型保留为可重现的试验选项。下一步若继续，应先定位节点间/模型加速度误差和路径余量，再决定局部动力学或安全约束方案；本轮没有自动增加稳定阶段、箱体反馈、速度限位或重调增益。
