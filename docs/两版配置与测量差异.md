# 共用核心中的两版差异

两版共用动力学、协同误差、独立 Q/P 权重、关节约束和求解流程。
场景差异通过配置与几何传入，不再复制整份求解器。

| 项目 | 平放 | 手持 |
| --- | --- | --- |
| 场景与初始抓取 | 原平放场景及抓取初始化 | 原手持场景及预载标定初始化 |
| 接触刚度 | 2793.166 N/m | 2419.3 N/m |
| 弹簧间隙 | 沿用平放标定 | 沿用手持标定并KEYI 换算到接触面 |
| 控制法向反馈 | 接触法向幅值之和，左负右正 | 作用在垫片上的世界 x 向合力 |
| 测量偏差 | 仅 x 力分量 | 保留旧六维偏差 |
| 默认移动距离 | 0.5 m | 0.05 m |
| 日志 | 原平放格式 | 原手持格式及更细物理步记录 |

统一的 `ContactMeasurement` 同时提供法向幅值、世界力、接触自身力矩、
接触面中心处的完整六维力偶、完整及切向关节载荷。
测量算法统一，反馈的物理口径由配置明确选择。

旧六维反馈中的力矩是各接触自身力矩之和，未加平移到共同原点的力臂项。
新测量另外提供包含力臂项的接触面力偶，用于对账；不替换旧反馈或旧日志力矩列。
实际广义载荷在接触点用平移与转动雅可比映射，不能重复加入力臂项。

默认完整载荷模式冻结“实测完整关节载荷减当前模型法向载荷”的残差，
预测期间再加各节点的模型法向载荷，避免法向力重复计入。
原切向模式作为已有可选项保留。

两版 x 向力模式系数和 y 向同步系数仍均为 0.8。
本次重构不调整参数、不加入箱体反馈，也不把不同场景的可达范围视为相同。
