# 两套 NMPCC 的代码组织与差异

> 历史记录：以下内容描述合并前的两套实现，已由 2026-10-09 共用核心重构取代。
> 当前结构请阅读 `代码阅读说明.md` 和 `两版配置与测量差异.md`。

本次只整理代码职责与注释。平放版和手持版继续使用各自的控制器，没有合并引擎，也没有调整控制参数、参数槽位、约束、参考轨迹或接触标定。

## 阅读顺序

先读场景入口的 `main()`，了解场景、抓取姿态和配置；再读 `run_case()`，依次查看参数采样、模型平衡初值、两次预热、控制更新和物理积分。参考轨迹位于同文件的 `PhaseReference`。

查看优化问题时，转到对应控制器的 `NMPCCCart.__init__()`：运动学与接触模型、合作误差、代价、约束、求解器依次构建。`solve()` 负责归一化参数、初始化全部节点、求解及失败重建。接口末尾的预测量用于诊断，完整状态轨迹还用于下一拍热启动。

| 文件 | 职责 |
| --- | --- |
| `exp2_nmpcc_latest.py` | 平放版场景、参考、采样与控制循环 |
| `nmpcc_cart.py` | 平放版独立 OCP 和求解接口 |
| `exp2_nmpcc_latest_grasp_pose.py` | 手持版场景、启动预压标定、参考与控制循环 |
| `nmpcc_cart_grasp_pose.py` | 手持版独立 OCP 和求解接口 |
| `diagnostics/flat_observation.py` | 平放版逐步观测、预测记录、失败现场和指标调用 |
| `diagnostics/handheld_observation.py` | 手持版对应记录，另保留预热与每个物理步的完整日志 |
| `exp2_experiments/flat_tools.py` | 平放版评价、CSV/NPZ 导出、绘图调用和实验选项 |
| `exp2_experiments/handheld_tools.py` | 手持版对应工具、源码归档、可选运行期权重与稳定阶段实验 |
| `exp2_experiments/sweeps.py` | 显式扫描的循环、重复运行与汇总表 |
| `diagnostics/measurements.py` | MuJoCo 测量、统一采样、接触载荷对账和限位记录基础函数 |

实验模块按原位置接收控制循环的观测数据；物理积分仍由入口执行。保留入口的 `summarize()`、手持版的 `save_run()` 包装接口，避免现有调用方因文件迁移失效。现有命令行选项和日志字段沿用原定义。

## 两个控制器的实际差异

| 项目 | 平放控制器 | 手持控制器 |
| --- | --- | --- |
| 外部参数宽度 | 191 | 201 |
| 测量偏置 | 左右各一个带符号法向力，共 2 维 | 左右各六维世界坐标力及力矩，共 12 维 |
| 偏置槽位 | `176:178` | `176:188` |
| 力增益槽位 | `178` | `188` |
| 左右参考力导数 | `179:191` | `189:201` |
| 内部 eta 参数 | 再追加 24 维，共 215 | 再追加 24 维，共 225 |
| 旧参数兼容 | 176、178、179 维补齐 | 176、188、189 维补齐 |
| 不传 `f_meas` | 使用名义力，重新将测量偏置设为零 | 保留输入参数中已有偏置 |
| 额外运行期接口 | `u_lim` 输入边界 | 另有 `set_If()`、`set_runtime_weights()`、首阶段 `u_prev/du_max` |
| 模型缓存版本 | `v7` | `grasp_v6` |

**六维测量接口不等于六维接触预测动力学。** 手持版保存完整测量力/力矩用于力误差锚定，但两版都只把预测的 x 向法向力通过接触点雅可比映射到关节动力学。默认入口把“当前完整实测接触广义载荷减当前模型法向载荷”作为冻结残差传入，所以切向载荷和接触力矩的当前影响已包含在残差中；它们未来如何变化仍未建模。

两版都保留：28 维关节状态、14 维力矩输入、独立阶段/终端权重、两个固定的 0.8、力误差直接乘 `kf_scale`、11 个状态节点完整初始化、模型平衡力矩种子、逐节点参考、物理关节角边界和失败重建。没有因为文件整理改变论文合作误差的结构。

两版 FK 的辅助实现独立维护。正常入口均显式提供接触点偏置与 `contact_tips`。不要把任意自定义 FK 字典直接互换：无 `contact_tips` 时的兼容回退写法并不相同。本轮不修改该旧接口行为。

## 属于场景而非控制器结构的差异

- 平放版刚度为 2793.166 N/m，零力模型接触点间距为 0.507537 m；手持版刚度为 2419.3 N/m，标定垫片中心间距为 0.248 m，换算到朝内接触面后传入控制器为 0.240 m。这些数值不应互相覆盖。
- 手持版重排物理左右臂，以满足控制器左右顺序；启动时用实测接触力校准 IK 压入量。平放版沿用自身场景和抓取流程。
- 当前默认搬运距离分别为平放 0.5 m、手持 0.05 m；对照 10 cm 必须显式传入 `--y_dist 0.10`。
- 两个入口显式传入已验证的控制配置。配置类的旧构造默认值仍为兼容调用保留；本次没有统一或修改这些数值。查实际运行参数应看入口及运行归档。
- 手持版额外实验接口依然可用，但默认不覆盖权重、不开启稳定阶段，也不启用首阶段力矩增量限制。

## 本次整理和维护经验

1. 先归档四个源文件，再拆分观测与导出。每个记录调用保留原来的采样时刻，避免“整理日志”意外改变物理状态和反力的对齐关系。
2. 删除临时 agent 日志及其磁盘写入，清理过期版本说明；中文注释解释当前物理含义和接口边界，历史数值留在实验报告里。
3. 参数布局不迁移，符号运算不改写，缓存模型版本不变。跨文件依赖显式传入，例如物理步长和场景中心，避免依赖原函数所在文件的全局变量。
4. 两套观测实现也分别保留，避免在本轮引入复杂的场景分支。共享的扫描工具仅组织实验，不包含控制器公式。
5. 实际触限、持续滑移、求解延迟都是原有控制问题；文件整理不能视为这些问题已经解决。手持 10 cm 的已知触限也不应因整理而隐藏。

前序物理修复见 [实施历史](nmpcc_implementation_history.md)，手持参数迁移与已知限制见 [手持迁移报告](nmpcc_handheld_flat_transfer.md)。本轮归档、固定命令和完整对照结果保存在 `D:\RobotSim\scratch\nmpcc_readability_20260908`。
