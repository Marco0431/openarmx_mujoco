# 测量锚定的理想弹簧

两场景通过 `--normal_force_law` 选择接触力预测，默认仍是 `smooth_positive`。
本轮只替换法向力预测子模型，不修改协同误差、代价权重、控制模式、关节边界或求解设置。

| 选项 | 法向力大小的计算 | 当前测量修正 |
| --- | --- | --- |
| `smooth_positive` | 对 `rest_gap - gap` 使用原平滑正部函数，再乘刚度 | 在名义力之外加偏差 |
| `ideal_unilateral` | `kx * max(0, rest_gap - gap)` | 在名义力之外加偏差 |
| `measured_anchored_ideal` | `max(0, measured_normal + kx * (anchor_gap - predicted_gap))` | 测量预载在截断内部 |

`gap` 是控制器右侧与左侧夹持面中心的世界 x 坐标差。每次控制更新只读取一次
当前间距和两侧测量力，作为 `anchor_gap` 与 `anchor_normal`，复制到包括终端的全部节点。
两侧分别截断，沿用原来刚度对总间距变化的定义，不额外乘二或除二。

在当前节点，新律预测法向力等于测量值；预测夹紧时按完整刚度增加，松开时按相同刚度减小。
卸载到零后不产生拉力。恰好为零时采用零导数；正力区通过总力表达式自动计算力导数。
手持版仍采用世界 x 分量，平放版仍采用接触法向幅值；本轮不混改测量口径。
显著反号的测量锚点会报错并保留失败现场，仅允许清除 1e-9 N 内的负浮点噪声。

## 相关代码

- `nmpcc/model.py`：总力、力导数、法向载荷映射和协同残差使用相同表达式。
- `nmpcc/controller.py`：采样锚点、计算完整接触负载减当前模型法向负载的冻结余项。
- `nmpcc/parameters.py`：命名参数编码、完整重放及旧日志兼容边界。
- `experiments/recording.py`：预热、逐节点参数、每 2 ms 接触和关节限位记录。

新律仍用 28 个状态和 14 个力矩输入。新增的是三个外部参数，不是优化变量。
旧两律保持 225 维参数；新律在末尾增加当前间距及两侧正法向力，共 228 维。
原 0:225 的位置和含义不变。模型版本 `shared_v3` 及接触律/参数布局共同隔离 DLL 缓存。

完整重放必须读取 `prediction.npz` 的 `parameters_shared_full` 与 `parameter_layout`。
`parameters` 和旧 CSV 是兼容视图，不能单独重放新律；失败文件同时保留原始完整参数。
新律日志中的 `force_nominal` 仍表示旧间距弹簧的诊断值，不能再通过
`force_nominal + force_bias` 重建最终预测法向力。请读取 `force` 或公开的 `predicted_force`。

## 运行

在 `openarmx_mujoco` 目录使用原环境执行：

```cmd
D:\acados_env\python.exe -u exp2_nmpcc_latest.py --no_viewer --y_dist 0.10 --normal_force_law measured_anchored_ideal
D:\acados_env\python.exe -u exp2_nmpcc_latest_grasp_pose.py --no_viewer --y_dist 0.05 --normal_force_law measured_anchored_ideal
```

分享目录的入口也支持相同选项。首次遇到新的结构指纹会编译，后续同配置复用缓存。
实验用的固定命令、源代码哈希、初始状态、MJB 和结果保存在
`D:/RobotSim/results/measured_anchored_contact_20261012/`，不随意调整其他参数来补偿结果。

## 适用范围

这是维持夹持附近的局部理想弹簧。`gap` 不是实际接触穿透深度，测量预载对应的是有效
弹簧形变，不能当成真实几何压缩；预测零力也不能单独证明实体已经分离。
箱体倾斜、有限接触面、箱体未来运动和冻结切向载荷近似仍然存在。
尤其法向力归零时，冻结余项不会自动消失，本轮没有实现完整的接触脱离或摩擦规划。
是否改善搬运必须根据同初态闭环对照判断。
