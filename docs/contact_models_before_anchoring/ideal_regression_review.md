# 理想接触候选：独立回归审查

结论：理想候选未通过本轮“不新增触限、不增加误差”的推广门槛。应保留实验选项与原始结果，生产默认恢复 smooth_positive；不能宣称理想模型已解决手持控制问题。以下检查只读取保存数据，使用独立 MjData 的 forward 更新接触几何及同状态 CasADi 函数评估，没有新闭环或优化求解。

## 对照完整性

两组配对的初始 qpos/qvel 逐元素完全一致，保存的 MJB 字节完全一致（SHA256 a6020bdc7fd6b25c836776cd6afd7ef3d0774c20331232ad39d5980e943fef7e）；args 只差 output_dir。配置仅差新增 normal_force_law=ideal_unilateral，旧缺省字段对应 smooth_positive。源文件差异为 scene/config/model/ocp/__init__ 和运行时 XML；XML 文本差异没有改变最终保存物理 MJB。不是通过姿态、动力学参数或限位修改得到的结果。

## 因果边界及最终入口

配对运行证明这些固定条件下有回归；同状态分析证明接触律会改变预测导数；几何分析证明中心间隙分支与有限面实际接触不等价。这些证据尚不能隔离哪一个后续机制单独导致某次触限，也没有运行反事实优化/闭环来证明改变某项即可消除失败。不得事后调系数、放宽限位或混入缩短行程来消除对照中的失败。

最终生产手持 CLI 默认为 smooth_positive，--normal_force_law ideal_unilateral 显式选候选；旧 args 无该字段仍使用 smooth。原候选 workspace/source、12 组运行、物理模型、失败证据均保持不变。共享 ideal 分支与 c=0 选零导数仍保留。门控后全部 52 项 diagnostics/tests 通过；该软件回归不是新的闭环验收，也不等于旧平滑模型在所有工况都安全。
