# 零系数可视化对照

双击项目根目录的 `run_flat_zero_coefficients.cmd` 可看平放版，`run_handheld_zero_coefficients.cmd` 可看手持版。每次生成独立输出目录，不覆盖旧结果。请一次运行一个窗口。

两版均把两臂的 y 向 eta_cop 与 x 向 eta_f 设为零，其余分量本来就是零，因此两套系数均为全零。保留原接触标定、初始抓取、关节限位、预测时域、求解器和代价权重，无额外扰动。

平放版仍使用 10 cm 行程及原时序。手持版使用已确认的 5 cm 行程，并取消 0/0 的保持阶段（`--t_hold 0`）：保留 0.5 s 夹紧参考过渡，0.5 s 开始搬运，5.7 s 停止，6.1 s 结束观察。只有手持零系数启动器采用此时序，其他系数组的保持时间不变。

取消保持不保证避免关节触限。已记录的手持 0/0 无保持实验仍有实际触限；完整结论见 `D:/RobotSim/results/nmpcc_handheld_short_move_20261012/ZERO_CHECK.md`。原有保持段的 0/0 记录保留，不与新时序混作同一实验。

此时 y 方向不再显式追求双臂同步，x 方向不再使用力误差反馈，控制误差使用各自的位置与速度参考。夹持力仍可能由压紧位置和真实接触产生，不能把零力系数理解成实际夹持力为零；参考中的 10 N 还用于原有压紧位置生成。

启动文件故意不传 `--no_viewer`，先直接运行现有闭环代码。原入口会在实验结束后关闭实时窗口，随后启动器自动打开 `replay_exp2.py` 回放窗口。回放初始暂停：**空格播放/暂停、R 从头开始、Esc 或关闭窗口退出**，默认半速循环播放。可拖动鼠标调整视角。回放采用每 10 ms 保存的实际状态，不求解、不执行物理积分；它不是另一轮实验。这里没有改变实时闭环的暂停行为，空格控制仅适用于回放窗口。

首次回放把本次生成的 XML 保存为 `replay_model.mjb`，核对开头、中间、结尾的双臂末端和箱体位置与原日志一致。它是运动学显示模型，不用于重新计算或评价接触力；验证结果见 `replay_validation.json`。自动回放紧接本次实验进行，之后用快照即可反复观看，不依赖后续运行覆盖的 XML。

平放版日志和图片均在 CMD 显示的输出目录。手持版完整诊断在显示目录，原 CSV/图片沿用其正式入口的 `results/exp2_latest_grasp_pose/` 路径。使用固定的 `D:\acados_env\python.exe`，不修改其他 Python 环境。可在 CMD 后附一个尚不存在的输出目录作为唯一参数。
